## Visão geral

### O desafio

Os usuários devem ser capazes de:

- Ocultar/Mostrar a resposta de uma pergunta quando ela for clicada.
- Navegar pelas perguntas e ocultar/mostrar respostas usando apenas a navegação por teclado (acessibilidade com `aria-expanded` e foco visível).
- Visualizar o layout ideal para a interface, dependendo do tamanho da tela do dispositivo (responsivo para mobile e desktop).
- Ver os estados de foco (*focus*) para todos os elementos interativos na página.

### Construído com

- Marcação HTML5 semântica
- Propriedades personalizadas CSS (CSS Variables)
- Flexbox
- Abordagem *Mobile-first*
- JavaScript Vanilla (para manipulação do DOM e interatividade do acordeão)

### O que eu aprendi

Durante o desenvolvimento deste projeto, pude consolidar a manipulação de estados interativos utilizando atributos de acessibilidade (`aria-expanded`) em conjunto com o JavaScript para controlar a abertura das respostas e a troca dinâmica dos ícones de mais/menos.

Também pratiquei a estilização de estados de foco focados em acessibilidade (`:focus-visible`) e a estruturação de layouts responsivos utilizando Flexbox e imagens de fundo adaptáveis para mobile e desktop.

### Desenvolvimento contínuo

Nos próximos projetos, pretendo continuar aprimorando minhas habilidades em lógica com JavaScript e estruturação CSS avançada, focando sempre em criar interfaces acessíveis, limpas e totalmente responsivas.
